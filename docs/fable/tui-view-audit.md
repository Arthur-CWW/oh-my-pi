Date: 2026-07-19  
Scope: `vendor/oh-my-pi/packages/coding-agent/src/modes`.

## Method, provenance, and current state

The baseline audit was exhaustive over `src/modes`: every `src/modes/**/*.ts` file was searched for component/selector/panel/dashboard/overlay declarations and for `SelectList`, `SettingsList`, `TablePreviewComponent`, `ScrollView`, `showOverlay`, `showSelector`, and `handleInput` seams. The 31 rows below are retained as the pre-convergence provenance record; their key and status descriptions are historical observations, not claims about the current implementation.

Key terms in the historical rows: `select-up/down` were the configurable selector actions (default arrows); selector Vim actions were `tui.select.vimUp/vimDown` (default `k/j`) when the underlying list permitted them. `ui.dismiss` was the configured dismissal action.

**Current result (HR-225): executed.** The active residual audit has zero rows. Shared ownership now lives under `src/modes/mvu/`, with domain components acting as route/view adapters.
