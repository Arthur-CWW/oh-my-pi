## Method

The prior 2026-07-07–11 evidence was retained and the window was extended with a fresh scan from **2026-07-12 00:00:00 UTC through 2026-07-13 03:10:42 UTC**. The scan stream-parsed 2,260 JSONL files under `~/.omp/agent/sessions/` one file at a time (including `-agents/` and other projects); it did not load the corpus or the largest ~20 MB journal at once. Collection prioritized `error`, `isError`, system notices, failed tool receipts, cancelled task envelopes, and user complaints before inspecting surrounding text.

The unit of frequency is a distinct incident unless the collector explicitly counted independent occurrences. Replayed user messages, taxonomy/ledger quotations, repeated banners, poll surfaces, and parent/child copies of the same failure are deduplicated. A failure shown in several UI/tool surfaces is counted once. Rankings favor leverage (data loss, blocked work, or failures across workflows) and then recurrence. `Fixed already` is based only on `docs/state/friction/fixed-2026-07.md` and commits listed there; no fix is inferred from nearby work.
