# Model availability

This is the repository's single source of truth for time-sensitive model availability and usage-limit announcements.

## Sources

Rows in the Updates table may be appended by `packages/availability-watcher`; run its `availability:sync` and `availability:check` scripts from that package.

- **@thsottiaux via Nitter RSS** — best source for the requested ChatGPT Pro/Codex usage-limit resets, bonus credits, and Fable availability posts. The watcher tries several public Nitter instances and remembers the last working instance.
- **[OpenAI News RSS](https://openai.com/news/rss.xml)** — OpenAI's official product-announcement feed. This was chosen over the OpenAI status feeds because status feeds report incidents and maintenance, not product availability windows.
