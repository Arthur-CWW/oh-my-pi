## SUMMARY

- Testing requires both a testing strategy and testable software; structure and APIs make hard behavior approachable.
- Snapshot (golden-file/ground-truth) tests are useful for complex outputs and produce informative diffs.
- Isolating side effects exposes the pure behavior inside stateful or I/O-heavy systems.
- Realistic inputs matter: otherwise a clean test can still be garbage-in, garbage-out.
- Ghostty uses snapshots for rasterized glyphs and images, including diffs for debugging regressions.
- GPU work can be tested by asserting CPU-side graphs/data, then comparing rendered output snapshots.
- The talk closes with reproducible VM/system testing as another layer beyond unit and integration tests.
