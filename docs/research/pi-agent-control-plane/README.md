# Pi agent control plane research

Reference notes collected while designing the local Pi/tmux control-plane project.

These are concise source digests, not perfect archival copies.

## Files

- `openai-harness-engineering-notes.md` — lessons from OpenAI’s harness-engineering post
- `openai-symphony-blog-notes.md` — lessons from the Symphony announcement / blog post
- `openai-symphony-spec-notes.md` — implementation-shaping notes from `openai/symphony` `SPEC.md`
- `codex-app-features-notes.md` — Codex app product/UX patterns relevant to this project
- `odysseus0z-orchestration-notes.md` — public social notes pointing at minimal Linear/worker orchestration patterns
- `source-urls.txt` — raw source URL list

## Why this directory exists

The control-plane spec is getting large, and several external references are shaping the design. These notes keep the important ideas repo-local so future agents can cite them without rediscovering everything from scratch.
