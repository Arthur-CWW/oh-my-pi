### Linked code repository from Source 3

Repository URL: https://github.com/abeliansoup/latwalk
Retrieved via GitHub API: 2026-07-06
Repository description observed: `abeliansoup/latwalk`; language Python; README title `Latent Walker`.

Relevant README excerpts (verbatim):

> Latent Walker turns a folder of images into an ordered visual walk. It embeds images with CLIP, DINO, color histograms, or a weighted ensemble, orders them so adjacent frames are visually related, and renders an MP4. If you add an audio track, image changes and effects can follow the beat, fast onset clusters, and pulse energy of the song.

> Builds a similarity path through an image set.
> Renders a smooth video from that path.
> Optionally syncs image changes to music.
> Adds optional crossfades, pulse brightness, chromatic shifts, negative flashes, glitch bands, and kinetic noise.
> Caches image features so visual/effect experiments do not need to re-embed every image.
> Provides optional post-processing with FILM frame interpolation for smoother transitions.

> The default path is tuned for coherence: `auto` prefers DINO-heavy ensemble features when available, with `--order localnn`, `--full-matrix-threshold 12000`, `--distance-precision float32`, and `--multistart 32`.

> The strongest general feature recipe has been `dino=0.55,clip=0.35,hist=0.10`.

> Keep `--crossfade-frames 0` when using FILM interpolation. Crossfading before FILM can create a smeared/jittery transition layer.

> For calmer videos, use `--change-mode beat`. For accent-aware timing, use `--change-mode middlepath`; it can snap weak beat-grid changes to nearby stronger onsets and preserve salient off-grid accents. For dense music sync, use `--change-mode hybrid`, then tune thresholds rather than adding constant midpoint inserts.

> FILM is not "maxed out" by the default `--source-fps 12 --factor 2` recipe. Lower `--source-fps` and raise `--factor` to make FILM synthesize more in-between motion, but expect more artifacts and slower renders.

> For FILM, 512px is the practical first target, 720px is a good higher-quality local target, and full 1080p should be tested on short clips before committing.

> `--effect-preset pulse`: pulse brightness/color with the audio.
> `--effect-preset pulse-negative`: adds short negative flashes on strong pulses.
> `--effect-preset glitch`: adds chromatic offsets and pulse-triggered glitch bands.
> `--effect-preset rave`: stronger glitch preset.
> `--noise-mode {off,speckle,grain,pulse-speckle}`: overlay kinetic noise without moving the image frame.
