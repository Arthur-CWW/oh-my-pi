## Detailed Description

**Camera Angles** lets you generate images from different viewpoints while staying consistent with a reference image.

Simply select a camera angle, and Arcads will generate new images that match that angle using your reference image as a base. This makes it easy to explore multiple perspectives without changing the subject or style.

You can also automatically generate **up to 10 key camera angles**, giving you a complete set of viewpoints in just a few clicks.

This feature is ideal for visual consistency, storyboarding, and creating multiple shots from a single reference.
