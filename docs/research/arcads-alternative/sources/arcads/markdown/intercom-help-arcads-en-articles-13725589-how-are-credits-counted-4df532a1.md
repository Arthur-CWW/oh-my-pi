Credits are not counted the same way for every generation.

The number of credits used depends on **the model or feature you choose**.

Below is the complete breakdown.

---

## **🎭 Talking Actor Models**

These models are priced either per minute and per actor

- **Talking Actor – Arcads 1.0** → 800 credits per minute, per actor
- **Talking Actor – Audio-Driven** → 800 credits per minute, per actor
- **Talking Actor – OmniHuman 1.5** → 800 credits per minute, per actor

⚠️ Important:

- If you use multiple actors in the same video, credits are counted **per actor**.
- Length is always rounded up.

**Example:**

A 2-minute video with 2 actors using OmniHuman 1.5 =

2 min × 2 actors = **3200 credits**
​
A 1 minute, 45 seconds video with 2 actors using OmniHumamn 1.5 =
2 minutes (1 min, 45s rounded up to 2 minutes) x 2 actors = **3200 credits**

## **🎬 Video Generation Models**

These models are priced per generation.

The credit cost depends on the model and complexity.

- **Grok** → 24 – 304 credits
- **Kling 3.0** → 176 – 560 credits
- **Kling 2.6** → 240 – 400 credits
- **Veo 3.1** → 800 credit
- **Sora 2** → 240 – 1200 credits
- **Sora 2 Pro** → 320 – 1200 credits
- **Seedeance 2.0** (480p) -> 96 - 360 credits
- **Seedance 2.0 (720p)** → 192 - 720 credits
- **Seedance 2.0** (1080p) -> 432 - 1620 credits

**Seedance 2.0 Flat reference video surcharge :**

- 1080p = + 1080 credits
- 720p = + 480 credits
- 480p = +240 credits

💡 Higher-end models generally consume more credits due to higher realism and rendering cost.

## **🖼 Image Generation**

- **Nano Banana Pro** → 100 free images per day
- **Seedream 40** → 100 free images per day

These do not consume paid credits within the daily free limit.

## **🎥 Presets**

- **Show Your App** → 200 credits
- **Unboxing POV** → 400 credits
- **Gesture** → 240 credits
- **Camera movement** → 240 credits
- **Product showcase** -> 800 credits
- **Fashion try on** -> 800 credits
- **Sora 2 actors** -> 800 credits

## **🛠 Tools**

Tools are priced individually per use.

- Extract frame -> 0 credits
- Prompt builder -> 8 credits
- Kling o3 video editor -> 400 credits
- Change voice -> 0 credits
- Transcribe -> 0 credits
- Camera angle -> 0 credits (100 free images / day)
- Translate video -> 240 credits
- Extend video -> 320 credits
- Remove background -> 0 credits
- Skin enhancer -> 160 credits
- Add captions -> 80 credits
- Hook repurposer -> 800 credits
- Upscale -> 80 credits per 10 sec
- Animate actor -> 800 credits
- Replace actor -> 800 credits

## **Why Does Pricing Vary?**

Arcads aggregates multiple AI models.

Each model has different infrastructure costs, rendering complexity, and output quality.

That’s why credits are calculated differently depending on the feature you use.

If you’re unsure how many credits your project will require, our support team is happy to help you estimate before generating.
