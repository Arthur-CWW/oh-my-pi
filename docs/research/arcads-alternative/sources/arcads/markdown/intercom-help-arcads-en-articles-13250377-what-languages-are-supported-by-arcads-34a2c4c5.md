## Pro Language Capabilities

With a **Pro plan**, you can:

- Create **custom voices**
- Define **custom accents and language variations**
- Manage all language specifics with **fine-grained control**, perfect for international campaigns

These features help teams deliver **precise, scalable, and consistent multilingual content**.
