What is the Workflow feature?

Workflows let you automate your entire content creation pipeline inside Arcads.

Written by Damien goubin
Updated over 2 weeks ago
Table of contents

Instead of generating assets step by step, you can:

  • Connect multiple AI models together

  • Reuse your assets (actors, products, prompts)

  • Generate multiple videos automatically

👉 Build once. Generate at scale.

🧠 How Workflows work

Workflows are built using nodes — each node is one step in your pipeline.

You:

  1. Add nodes (inputs, models, tools)

  2. Connect them together

  3. Run the workflow

👉 Everything runs automatically

🎬 Example #1 : Generate Multiple UGC Ads Automatically

Link here : https://app.arcads.ai/flow/public/DEeXmhsWN_dOUlH_ymn35HO-

This workflow is built to solve a very simple problem:

👉 You have:

  • one product

  • holding or showing the product

It uses LLMs to:

  • Break them into visual moments

🎬 EXAMPLE #7: Video Clone Workflow | Batch Character Replacement

Run the same offer with a 25-year-old, a 40-year-old, and a 60-year-old — and let the data tell you who converts best.

What it does Takes one source video and replicates it across 4 new AI characters — same script, same timing, different faces and voices.

Inputs

  • Source video — the original clip you want to clone

  • Character prompts — write a description for each character, or upload images directly

  • Voices — select a voice for each new character

Output 4 video variations — same script, 4 different characters with matching voices

🎬 EXAMPLE #8: UGC Content Engine | Product Showcase + Translation

Found a script that converts? Feed it straight into the engine and multiply it across 10 characters and 2 markets in one run. No re-shooting, no briefing creators.

What it does Takes one script and one product image, and generates 20 ready-to-post UGC videos across 10 AI characters in English and Spanish.

Inputs

  • Product image — clean product photo

  • Script — your UGC script (8 sec of dialogue)

  • Character avatars — headshots of AI or real characters (x10)

How it works

  1. Upload product image, script, and character avatars

  2. Workflow generates 2 talking-head videos per character

  3. Auto-translates and renders Spanish versions

  4. 20 clips delivered, ready to post

Output 20 x 8-second clips — 10 English, 10 Spanish

👉 Open workflow: https://app.arcads.ai/flow/public/vKSfDLlD5IYkU-tkrX2E557Q
