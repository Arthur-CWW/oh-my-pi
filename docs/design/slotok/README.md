## Current preference summary

Slotok should feel like a clean native workbench/editor, not a dark analytics dashboard. Default to a Codex-like light theme: soft sidebar, white central document pane, subtle cards, thin borders, quiet typography, restrained accent color, and lightweight right inspector/action panels.
