# tweet-viewer

Planned local viewer for the Twitter/X archive.

Scope:

- local-only search over archived users/tweets/threads/media
- Twitter-like keyboard shortcuts (`j`, `k`, `/`, `o`, `v`, `?`)
- quote tweet expansion
- full thread view for replies/conversations
- labels, notes, and categories for inspiration review

The viewer should read normalized archive data from ignored `data/twitter-archive/` or an explicit archive path.
