# Twitter/X archive imports

This folder centralizes local tweet-archive material that previously lived in separate projects/downloads.

## Contents

- `legacy-tweet-archives/` — snapshot from `/Users/arthur/projects/tweet-archives`.
  - `raw/tweets.db` — legacy SQLite DB.
  - `raw/gcr-tweets.csv` — source CSV from the legacy app.
  - `raw/wayback/raw/*.json` — raw Wayback oEmbed payloads from the legacy hydrator.
  - `normalized/entities/*.jsonl` — normalized monorepo archive entities generated by `packages/twitter-archive/src/import-legacy-sqlite.ts`.
- `downloads/wayback-index/` — downloaded Wayback tweet-index exports from `~/Downloads`.
- `external-notes/pleometric.md` — local Pleometric note copied from the HSK-deck repo for context.

## Regenerate normalized JSONL

```bash
bun packages/twitter-archive/src/import-legacy-sqlite.ts \
  --db packages/twitter-archive/imports/legacy-tweet-archives/raw/tweets.db \
  --out packages/twitter-archive/imports/legacy-tweet-archives/normalized \
  --target gcrclassic \
  --username gcrclassic \
  --display-name GCRClassic
```

## Notes

This is a local-first research/import area, not a live scraper. Do not archive private/locked content or bypass X/Twitter rate limits/auth controls.
