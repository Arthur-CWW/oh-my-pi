## Design decision and invariant

- Publisher writes only durable JSONL outbox lines through `appendOutboxLine`; it never opens SQLite or imports ledger storage.
- Each session has an in-memory state keyed by `ctx.sessionManager.getSessionId()` and writes to `outboxPathFor(sessionId)`, honoring `AGENT_CONTROL_PLANE_OUTBOX_DIR`; the OMP session file is preserved in session/event payload metadata.
- `seq` resumes from the existing outbox line count, then increments only after a successful synchronous append.
- `before_provider_request` caches the latest provider payload per session and the next assistant `message_end` embeds it in the `modelCall` payload as `rawRequest` with `rawRequestSupport`.
- `turn_start` is cached and emitted as a generic event; the `turn` envelope is emitted only at `turn_end` with canonical required fields and cached `startedAt`/context/tool counts.
- IngestTailer confirmed canonical turn/modelCall required fields; publisher payloads include all required fields and keep extra model telemetry/raw-request keys for ingest to ignore.
- Every registered handler is wrapped; handler failures try to append a `publisherError` event and otherwise swallow to avoid throwing into OMP.
