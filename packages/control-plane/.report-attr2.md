## Core design decision and invariant

Assistant `message_end` still emits the `modelCall` envelope immediately. The publisher now also computes a stable attribution string as `provider/model[:thinkingLevel]`, stores it on that `modelCall` payload, and caches `{modelCallId, messageTimestamp, attribution}` in session state.

The next attribution-capable session event (`turn_end`, `message_start`, or `session_shutdown`) probes `ctx.sessionManager.getEntries()` when available, scans only the recent tail, matches assistant entries by `entry.message.timestamp`, emits an `event` envelope with inner kind `attribution`, then clears the cache slot. After two failed probes it emits inner kind `attributionMiss` and clears the slot. A hard cache cap also prevents unbounded growth.

Ledger attribution is a derived, idempotent write: `attributeModelCall(modelCallId, entryId)` updates only rows whose `entryId IS NULL`. Ingest records the attribution event row as the durable source and applies the derived model-call update during the same ingest invocation; re-ingest safely becomes a no-op for the update.

## Deviations / technical doubts

- No intentional deviations from PKT-3.
- The miss threshold is `probes >= 2`, meaning the second failed attribution-capable event emits `attributionMiss`. This follows the explicit test requirement: “after 2 events → attributionMiss.”
- The match key is exactly the scouted `message.timestamp` equality. I considered also falling back to entry-level `timestamp` or model, but did not implement that because PKT-3 pins `message.timestamp`; mixing keys could misattribute retries/fallbacks.
- If `ctx.sessionManager.getEntries` is absent, the publisher does not probe or emit a miss solely because the API is unavailable. It still caps cache growth. This preserves compatibility with harness contexts that have not exposed the seam.

## Risks / blockers

- `attribution` and `attributionMiss` are stored as generic event rows via the existing event envelope shape; consumers must read `events.kind` for the inner kind.
- I did not run tests, typecheck, lint, formatters, package managers, or project-wide commands because this subagent role forbids them. Changes are compile-plausible by inspection only.
