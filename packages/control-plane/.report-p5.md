## Design notes

- Checked the separate `@effect/cli` package: latest `@effect/cli@0.75.2` peers on `effect@^3.21.2`, so I did not add it against the package's Effect v4 beta contract. The CLI uses a small typed parser with the same command surface.
- JSON mode serializes the store/ingest return values directly: `statusSummary()`, `listModelCalls()`, `listEvents()`, and `ingestOutbox()` results are not reshaped.
- The CLI constructs `openLedger(dbPath)` inside each command execution path so `--db` selects the scoped LedgerStore layer per invocation.
- `model-calls` defaults to `--limit 50`; `events` also defaults to 50 to keep output bounded.
- Storage/artifact failures are folded into stderr JSON `{error, class}` and exit code 1. Usage errors use the same JSON envelope with class `UsageError`.
