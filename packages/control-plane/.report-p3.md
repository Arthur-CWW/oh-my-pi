## Design / invariants

- Instrumentation requires `LedgerStore` from context and returns the inner success value unchanged.
- Failures are observed with `Effect.matchCauseEffect`, recorded, then re-failed with `Effect.failCause(cause)` so typed failures/interrupt/defect causes are not swallowed by the wrapper.
- Latency uses `Clock.currentTimeMillis` before and after the inner effect; no `Date.now`, `Math.random`, or `randomUUID` in `src/telemetry.ts`.
- Model success always records outcome `ok`; model failure records extractor/classifier outcome, defaulting to `error`.
- Provider success always records outcome `ok`; provider failure records extractor/classifier outcome, defaulting to `error`.
- IDs are caller-supplied when provided, otherwise deterministic from session plus seq/packet/input hash. No random IDs.
- Raw model request and response artifacts are inserted before `recordModelCall`; provider raw request artifact is inserted only when supplied before `recordProviderCall`.
